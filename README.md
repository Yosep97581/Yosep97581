## 🚀 Featured Project

### 🧠 [UniMind AI](https://github.com/Yosep97581/Unimind-AI)

A local AI-powered study assistant designed to help students learn more effectively using their own university learning materials.

**Key Features:**
- Upload and interact with multiple PDF documents
- Ask questions with answers grounded in source materials
- Generate summaries, flashcards, and practice questions
- Search documents using vector embeddings and RAG
- Run language models locally using Ollama
- Maintain a persistent document knowledge base

**Technologies:** Python, Streamlit, Ollama, ChromaDB, RAG
